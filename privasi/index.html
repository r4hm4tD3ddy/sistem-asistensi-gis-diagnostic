2. Izin Google dan akses Drive

Masuk dengan Google dan memberikan izin Drive adalah proses yang terkait tetapi berbeda. Aplikasi menggunakan identitas Google untuk login. Fitur Drive meminta izin untuk membuat, membaca, mengunggah, memperbarui dan mengatur akses file/folder yang dipakai dalam layanan.

Koneksi Drive otomatis mahasiswa menggunakan izin https://www.googleapis.com/auth/drive. Izin ini secara teknis memungkinkan akses luas ke file Drive, bukan hanya satu file yang dipilih. Fitur aplikasi menggunakannya untuk folder dan dokumen bimbingan, termasuk file yang sebelumnya dibuat melalui jalur izin aplikasi dan penyesuaian akses pembimbing. Rincian izin ditampilkan Google ketika Anda memberikan persetujuan.

Koneksi otomatis dapat menyimpan otorisasi yang dapat diperbarui agar pengajuan dan pembaruan akses berikutnya dapat diproses tanpa mengulangi persetujuan setiap kali. Pencabutan izin, berakhirnya otorisasi atau kebijakan akun Google dapat mengharuskan Anda menghubungkan ulang.

3. Penyimpanan dan akses pengelola

Aplikasi berjalan menggunakan Google Apps Script. Data akun, akademik dan riwayat disimpan pada Google Sheets yang digunakan sebagai database. Profil, konfigurasi dan token koneksi otomatis disimpan pada Script Properties proyek Apps Script. Berkas diproses melalui Google Drive; salinan sementara atau cache dapat digunakan saat unggah/verifikasi.

Dokumen mahasiswa, foto profil baru dan bukti pembayaran dosen disimpan pada Drive akun pemilik sesuai fitur yang digunakan. Aset bersama aplikasi dikelola oleh pengelola. File/profil dari jalur penyimpanan lama dapat tetap berada pada penyimpanan sebelumnya sampai ditangani melalui proses pengelolaan yang sesuai.

Pengelola/pemilik proyek dan editor teknis yang berwenang merupakan pihak tepercaya yang mempunyai akses teknis ke database dan pengaturan proyek, termasuk token yang tersimpan. Token tidak ditampilkan pada halaman informasi publik atau disertakan dalam source publik. Penyimpanan Script Properties bukan brankas dengan enkripsi terpisah pada tingkat aplikasi.

4. Pembagian data

Data ditampilkan kepada mahasiswa, pembimbing dan pengelola sesuai peran dan relasinya. Akses dokumen mengikuti pengajuan serta tahap bimbingan: draf yang belum diajukan tidak ditampilkan sebagai dokumen pemeriksaan dosen. Pembimbing tidak diberikan akses Folder Master melalui alur aplikasi; file pengajuan mendapat akses sesuai kebijakan tahap yang berlaku.

Pengelola dapat membaca bukti pembayaran untuk verifikasi. Akun pelaksana server dapat memperoleh akses baca khusus pada file yang diperlukan untuk menampilkan foto atau memverifikasi bukti. Mengunggah file melalui fitur tersebut tidak menjadikan file publik. Berbagi manual oleh pemilik di luar aplikasi mengikuti pengaturan Drive pemilik sendiri.

Google menyediakan infrastruktur autentikasi, Drive, Sheets dan Apps Script. GitHub Pages menyediakan halaman informasi dan halaman login. Notifikasi di portal dan, jika diaktifkan pengelola, email dapat memuat informasi kegiatan kepada pihak terkait. Penggunaan layanan Google dan GitHub juga mengikuti kebijakan penyedia masing-masing.

5. Batas penggunaan data Google

Data Google digunakan untuk menyediakan serta mendukung fitur bimbingan dan administrasi yang dijelaskan di sini. Data tersebut tidak dijual, tidak digunakan untuk iklan yang dipersonalisasi, dan tidak digunakan untuk melatih model AI umum.

Penggunaan serta pemindahan informasi yang diterima dari API Google mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use. Akses manusia oleh pihak pengelola yang berwenang dibatasi pada kebutuhan layanan, dukungan, keamanan dan kewajiban yang berlaku.

6. Masa simpan, koreksi dan penghapusan

Logout atau pemutusan koneksi Drive tidak otomatis menghapus akun, riwayat akademik, keputusan pembimbing, bukti pembayaran, maupun file. Data dan arsip tersebut tetap tersimpan pada penyimpanan aplikasi/Drive sampai ditangani melalui proses pengelolaan atau penghapusan yang sesuai. Aplikasi tidak menerapkan satu jangka penghapusan otomatis yang sama untuk semua arsip.

Pemilik Drive tetap mempunyai kendali atas berkasnya; perubahan atau penghapusan langsung dari Drive dapat memengaruhi ketersediaan dokumen di portal. Pembatalan/pengarsipan pembayaran di portal menjaga riwayat dan tidak otomatis menghapus file bukti.

Untuk meminta akses, koreksi atau penghapusan data aplikasi, hubungi rahmatdeddy@ung.ac.id dengan informasi akun dan data yang dimaksud. Pengelola perlu mencocokkan identitas pemohon serta menjelaskan penanganan data terkait riwayat bimbingan, arsip atau kewajiban yang berlaku. Jangan mengirim kata sandi, token atau Client Secret melalui email.

7. Memutuskan koneksi dan mencabut izin

Di portal mahasiswa, buka Profil → Koneksi Google Drive → Kelola koneksi untuk memutus koneksi otomatis. Aplikasi menghapus koneksi/token yang tersimpan untuk jalur tersebut dan mencoba mencabut otorisasi Google. Jika pencabutan Google belum terkonfirmasi, portal meminta Anda mencabutnya juga melalui pengaturan akun Google.

Anda dapat meninjau dan mencabut koneksi melalui koneksi pihak ketiga pada akun Google. Pemutusan menghentikan operasi otomatis berikutnya sampai dihubungkan ulang, tetapi tidak menghapus file atau otomatis mencabut izin pembimbing yang sudah diberikan pada file. Pengaturan berbagi file dapat ditinjau pada Drive pemilik.

8. Perubahan kebijakan dan kontak

Perubahan penggunaan data dijelaskan melalui pembaruan halaman ini. Tanggal pembaruan tercantum di bagian atas. Untuk pertanyaan privasi atau koneksi Google, hubungi Pengelola Sistem di rahmatdeddy@ung.ac.id.
